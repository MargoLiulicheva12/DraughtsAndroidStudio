# Шашки — классическая настольная игра для Android
Классическая игра в русские шашки с возможностью игры против компьютера или с другом на одном устройстве. Реализована полная логика игры, анимация ходов и три уровня сложности.

## Особенности
- **Два режима игры:**
  - Два игрока на одном устройстве
  - Против компьютера с тремя уровнями сложности
- **Полная реализация правил русских шашек:**
  - Обязательное взятие фигур
  - Превращение в дамку при достижении последнего ряда
  - Дамка ходит на любое расстояние
  - Бить можно вперёд и назад
  - Правило 40 ходов без взятия/Тройное повторение позиции/Недостаток фигур для победы (ничья)
- **Умный компьютерный соперник:**
  - Легкий уровень: случайные ходы
  - Средний уровень: выбор лучшего хода по оценке позиции
  - Сложный уровень: алгоритм минимакс с альфа-бета отсечением
- **Визуальные эффекты:**
  - Плавная анимация перемещения фигур
  - Подсветка выбранной клетки
  - Визуальное различие простых шашек и дамок (золотая точка)
  - Переворот доски при игре чёрными
- **Игровой интерфейс:**
  - Отображение счётчиков съеденных фигур
  - Показ последнего хода в шахматной нотации
  - Информация о текущем ходе с предупреждением об обязательном взятии

## Инструкция по запуску
1. Перейдите в раздел Releases
2. Скачайте файл app-debug.apk
3. Перенесите на устройство и откройте для установки

## Использованные технологии
- **Язык:** Kotlin
- **Минимальная версия SDK:** 21 (Android 5.0)
- **Архитектура:** MVC с элементами MVVM
- **UI компоненты:** 
  - Material Design Components
  - ConstraintLayout
  - Кастомное View для отрисовки доски
- **Анимация:** ValueAnimator
- **ИИ:** Минимакс с альфа-бета отсечением
